# 🔍 심화 기술 분석 (Technical Deep Dive): Go Data Types & Formatting Verbs

### 1. Go 기본 데이터 타입의 이해

Go 언어의 기초가 되는 데이터 타입들은 각각 고유한 특성을 가지며, 메모리에 저장되는 방식과 표현 방식이 다릅니다.

| 타입 (Type) | 설명 | 제로 값 (Zero Value) |
| :--- | :--- | :--- |
| `int` | 정수형 (Integer) | `0` |
| `float6 4` | 부동 소수점형 (Floating Point) | `0.0` |
| `string` | 문자열 (String) | `""` (빈 문자열) |
| `bool` | 불리언 (Boolean) | `false` |

### 2. `fmt` 패키지의 서식 지정자 (Formatting Verbs) 마스터하기

`fmt.Printf`와 같은 함수를 사용할 때, 데이터의 형식을 제어하기 위해 사용하는 **서식 지정자(Verbs)** 활용법은 Go 프로그래밍의 핵심입니다.

#### 🚀 주요 서식 지정자 기능
- **`%v` (Value)**: **가장 다재다능한 지정자.** 타입에 상관없이 해당 데이터의 기본 포맷으로 출력합니다. (Default format)
- **`%d` (Decimal)**: **정수형 전용.** `int`, `int64` 등의 정수 데이터를 10진수 형태로 출력합니다.
- **`%.2f` (Float precision)**: **소수점 제어.** `float64` 데이터를 출력할 때 소수점 아래 자릿수를 지정할 수 있습니다. (예: `%.2f`는 소수점 둘째 자리까지 출력)
- **`%s` (String)**: **문자열 전용.** 텍란 형태의 문자열 데이터를 출력합니다.
- **`%t` (Boolean)**: **논리값 전용.** `true` 또는 `false`를 문자열 형태로 출력합니다.

### 3. 개발 시 유의사항 및 팁

**가. 정밀도 제어의 중요성**
금융 관련 애플리케이션이나 과학 계산 시, `float64`의 소수점 자릿수를 `%f`로 무분별하게 출력하면 오차가 커 보일 수 있습니다. 반드시 `%.2f` 또는 `%.nf` 형식을 사용하여 비즈니스 로 맵에 맞는 정밀도를 유지해야 합니다.

**나. `%v`와 `%+v`의 활용**
구조체(Struct)를 다룰 때는 `%v` 대신 `%+v`를 사용하여 필드 이름까지 함께 출력함으로써 디버깅 효율을 극대화할 수 있습니다.

**다. 타입 안전성 (Type Safety)**
Go는 강타입(Strongly Typed) 언어입니다. `int` 타입을 `%s`로 출력하려고 시도하면 런타임 에러는 발생하지 않더라도, 의도치 않은 문자열 표현이 나타나거나 논리적 오류가 발생할 수 있으므로 타입에 맞는 지정자 사용이 필수적입니다.
