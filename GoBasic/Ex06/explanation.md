# 🔍 심화 기술 분석 (Technical Deep Dive): Go Constants & Iota Mechanism

### 1. Go 상수(`const`)의 특성과 이점

Go 언어에서 `const`는 런타임이 아닌 **컴파일 타임(Compile-time)**에 그 값이 결정되는 불변(Immutable) 식별자입니다.

* **컴파일 타임 결정**: 프로그램 실행 중에 값이 변할 수 없으므로, 런타임 오버헤드가 없으며 컴파일러가 최적화할 수 있는 강력한 힌트가 됩니다.
* **불변성(Immutability)**: 한 번 정의된 상수는 재할당이 불가능하여, 의도치 않은 값의 변경을 원천적으로 차단하여 코드의 안정성을 높입니다.
* **타입 안전성(Type Safety)**: `const`는 기본 타입뿐만 아니라 사용자 정의 타입을 가질 수 있어, 런타임 타입 오류를 컴파일 단계에서 잡아낼 수 있습니다.

### 2. `iota`를 이용한 혁신적인 열거형(Enumeration) 생성

Go의 `iota`는 `const` 블록 내에서 **0부터 시작하여 순차적으로 증가하는 상수 생성기** 역할을 수행합니다.

#### 🚀 `iota`의 핵심 동작 원리
* **자동 계산**: `const` 키지 블록의 첫 번째 라인에서 0으로 초기화되며, 새로운 라인이 나타날 때마다 값이 1씩 증가합니다.
* **연쇄적 할당**: `iota`를 명시적으로 사용하지 않더라도, 이전 줄의 식을 참조하여 값이 자동으로 계산됩니다.

#### 💡 `iota` 활용 패턴 (Code Examples)

**가. 기본 패턴 (0-indexed)**
```go
const (
    Pending = iota // 0
    Active         // 1
    Deleted        // 2
)
```
*상태 코드나 시스템 상태를 정의할 때 가장 많이 사용되는 방식입니다.*

**나. 오프셋 패턴 (1-indexed)**
```go
const (
    RankOne    = iota + 1 // 1
    RankTwo               // 2
    RankThree             // 3
)

```
*데이터베이스의 ID나 순위(Rank), 혹은 1부터 시작해야 하는 논리적 수열을 만들 때 유용합니다.*

**다. 스킵(Skip) 패턴**
```go
const (
    _ = iota // 0을 건너뛰기 위해 사용
    First    // 1
    Second   // 2
)
```

### 3. 개발자 가이드: `const` vs `var`

| 특성 | `const` | `var` |
| :--- | :--- | :--- |
| **결정 시점** | 컴파일 타임 (Compile-time) | 런타임 (Runtime) |
| **재할당** | 불가능 (Immutable) | 가능 (Mutable) |
| **사용 예시** | 수학적 상수(`Pi`), 설정값, 열거형 | 사용자 입력, 계산 결과, 상태 변경 변수 |
| **성능** | 최적화에 유리함 | 런타임 오버헤드 존재 가능성 |

**결론**: 시스템의 상태, 설정값, 변하지 않는 물리적 상수 등은 반드시 `const`를 사용하여 컴파일러가 최적화할 수 있도록 하고, 프로그램의 무결성을 보장해야 합니다.
