# 🔍 심화 기술 분석 (Technical Deep Dive): Go Function Parameters & Multiple Return Values

Go 언어의 함수는 다른 프로그래밍 언어와 차별화되는 두 가지 강력한 특징을 가지고 있습니다: **다중 반환값(Multiple Return Values)**과 **명확한 에러 처리 메커적니즘**입니다. 이번 유닛에서는 이를 어떻게 활용하여 견고한 로직을 작성하는지 분석합니다.

### 1. 다중 반환값 (Multiple Return Values)

Go 함수는 단일 값뿐만 아니라 여러 개의 값을 동시에 반환할 수 있습니다. 이는 단순히 데이터를 전달하는 것을 넘어, **데이터와 상태(성공/실패)를 하나의 단위로 묶어서 전달**할 수 있게 합니다.

**실험 사례 분석:**
```go
// 몫과 나머지를 동시에 반환하는 패턴
func divide(a, b int) (int, int) {
    return a / b, a % b
}

q, r := divide(10, 3)
// q = 3, r = 1
```
위와 같이 `(int, int)` 타입을 반환함으로써, 한 번의 호출로 연산 결과와 나머지라는 두 가지 상태를 독립적이면서도 결합된 형태로 받아올 수 있습니다.

### 2. 에러 처리의 표준 패턴 (The Error Handling Pattern)

Go에서 다중 반환값의 가장 중요한 용도는 `error` 인터페이스를 반환하는 것입니다. 함수가 연산을 수행한 후, 결과값이 유효한지 여부를 `error` 타입을 통해 함께 반환함으로써 호출 측에서 즉시 대응할 수 있게 합니다.

### 3. 매개변수 전달: 값의 복사 (Pass by Value)

Go의 함수 호출은 기본적으로 **값 전달(Pass by Value)** 방식을 따릅니다. 즉, 함수에 인자를 전달하면 해당 인자의 **복사본**이 생성되어 함수 내부로 전달됩니다.

**중요한 실험적 관찰:**
- 함수 내부에서 매개변수(예: `int`)의 값을 변경하더라도, 함수 외부의 원본 변수 값은 변하지 않습니다.
- 슬라이스(`[]int`)와 같은 참조형 타입의 경우, 슬라이스 구조체 자체(포인터, 길이, 용량 포함)는 복사되지만, 내부의 요소들은 동일한 메모리 공간을 가리키므로 내부 요소 수정은 외부에도 영향을 미칩니다.

### 4. 요약 및 결론

Go의 함수 메커니즘은 **"실패할 수 있는 모든 연산은 에러를 반환한다"**는 원칙을 지원하기 위해 최적화되어 있습니다.
- **다중 반환값**은 복잡한 상태를 단순한 구조로 전달합니다.
- **에러 반환**은 프로그램의 예측 가능성을 높입니다.
- **값 전달** 방식은 함수 간의 부수 효과를 최소화하여 코드의 안정성을 보장합니다.
