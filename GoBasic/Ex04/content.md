# 🎯 학습 목표 (Learning Objectives)
Go 언어의 가장 기초적인 데이터 저장 방식인 **변수 선언**의 다양한 문법을 익히고, 각 선언 방식이 갖는 특징(Scope, Type Inference, Initialization)을 이해합니다.

# 💡 핵심 포인트 (Key Points)
- **`var` 키워드를 이용한 선언**:
    - 명시적 타입 지정(`var name string`)과 타입 추론(`var name = "value"`)의 차이.
    - 패키지 레벨(Package-level) 변수 선언 및 전역 변수의 특성.
- **단축 변수 선언 (`:=`)**:
    - 함수 내부(Local scope)에서만 사용 가능한 간결한 선언 방식.
    - 타입 추론을 통한 코드 가독성 향상.
- **제로 값 (Zero Value)**:
    - 변수 선언 시 초기화하지 않았을 때 Go가 자동으로 할당하는 기본값(`0`, `""`, `false`, `nil` 등) 이해.
- **변수의 범위 (Scope)**:
    - 블록(`{ }`) 단위의 변수 유효 범위 이해.

# 🛠️ 검증 시나리오 (Verification Scenario)
1. **코드 구현**: `var`와 `:=`를 모두 사용하여 다양한 변수를 선언하고 그 값을 출력하는 `example.go` 작성.
2. **런타임 검증**: `go run`을 통해 각 변수가 의도한 값(특히 제로 값)을 정확히 출력하는지 확인.
3. **컴파일 검증**: `go build`를 통해 실행 가능한 바이너리를 생성하고 실행 확인.
