# 1.1.1 Go SDK 설치 및 환경 변수 설정

## 학습 목표
- Go 언어 개발을 위한 SDK 설치 과정을 이해한다.
- Go 환경 변수(`GOROOT`, `GOPATH`, `PATH`)의 역할을 이해하고 설정 방법을 익힌다.
- 설치된 Go 버전을 확인하고 실행 가능한 상태인지 검증한다.

## 주요 학습 포인트
1. **Go SDK 설치**: 운영체제별 설치 방법 (Installer, Package Manager 등).
2. **GOROOT**: Go SDK가 설치된 디렉토리 경로 설정.
3. **GOPATH**: Go 작업 공간(Workspace) 및 패키지 저장소 설정.
*참고: Go 1.11 이후 모듈 모드(Go Modules) 도입으로 GOPATH의 비중이 줄었으나, 여리전히 기본 개념으로 중요함.*
4. **PATH 설정**: 터미널 어디서든 `go` 명령어를 사용할 수 있도록 실행 파일 경로를 환경 변수에 추가.
5. **환경 검증**: `go version`, `go env` 명령어를 통한 설정 확인.
